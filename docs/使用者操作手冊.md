# 使用者操作手冊

通學區案件期程暨發文管理系統

---

## 1. 登入與登出

1. 開啟系統網址，輸入公司 Email 與密碼登入。
2. 連續輸入錯誤 5 次，帳號會暫時鎖定 15 分鐘。
3. 忘記密碼請聯絡管理員重設。
4. 左側選單最下方可「登出」。閒置超過 12 小時需重新登入。
5. 首次登入請至「系統設定 → 個人帳號」變更密碼。

### 1.1 權限：誰可以標記完成

- **標記完成、變更工作狀態**（含「標記已創稿」「標記已提供圖說」「我已寄出，標記完成」「標記審查會議／會勘已辦理」）**僅限管理員**。
- 其他使用者只能檢視進度，仍可編輯公文與 Email 草稿；這些按鈕不會顯示給他們。
- **創稿工作只顯示給管理員**：事前規劃報告書創稿、審查後／會勘後修正圖說創稿，不會出現在一般使用者的儀表板、工作待辦、行事曆與案件頁。

### 1.2 安裝到電腦（桌面圖示）

用 Chrome 或 Edge 開啟並登入系統後，可以把系統安裝成電腦上的應用程式：

- 方法一：左側選單下方按「**安裝到電腦（桌面圖示）**」→「安裝」。
- 方法二：網址列右側的「安裝」圖示（螢幕加向下箭頭），或右上角「⋯」→「投放、儲存與分享」／「應用程式」→「**安裝通學區案件**」。

**手機**：
- Android：用 Chrome 開啟並登入 → 選單（☰）下方「安裝到電腦／手機」，或右上角「⋮」→「安裝應用程式」／「加到主畫面」。
- iPhone／iPad：用 **Safari** 開啟並登入 → 下方「分享」（方框加向上箭頭）→「**加入主畫面**」→「新增」。

安裝後會有桌面圖示與開始功能表項目，以獨立視窗開啟（沒有網址列），可釘選到工作列；系統更新時會自動使用最新版本，不需重新安裝。仍需連上網路使用。

## 3. 儀表板

- 上方統計卡：今日到期、明日到期、未來 7 天到期、已逾期、待創稿、待提供圖說、待寄送 Email、待上傳簡報、本週審查會議、本週會勘。點選可跳至對應區塊。
- 「到期工作」與「待辦分類」以分頁切換。每張工作卡片顯示學校、工作類型、截止日、剩餘工作天、負責人、狀態，並可直接：
  - **查看案件**
  - **產生公文**（創稿／發文類工作）：開啟既有草稿，沒有則依範本建立
  - **產生 Email**（寄簡報、會議紀錄、會勘紀錄）
  - **開啟上傳網址**（上傳會勘簡報）
  - **標記完成**
- 右上角可切換「全部案件／我負責的」。
- 「各學校進度」顯示每校完成比例、逾期數與下一項工作。

剩餘工作天說明：「今日到期」＝ 0；「剩 3 工作天」；「逾期 2 工作天」。標示「暫估」者表示該年度官方辦公日曆尚未匯入，期限僅排除週末；鎖頭圖示表示已人工鎖定期限。

## 4. 學校案件

### 4.0 計畫分類

- 「學校案件」頁上方有計畫分頁（全部計畫／116年度／115年度…），括號內為案件數。
- 在某個計畫分頁按「新增案件」，計畫名稱會自動選好該計畫。
- 新增案件時「計畫名稱」為下拉選單；選「＋ 其他計畫（自行輸入）」可建立新年度計畫，之後會自動出現在選單與分頁中。
- 儀表板、工作待辦、行事曆都可以用「計畫」下拉選單只看某一年度。

### 4.1 新增案件

「學校案件 → 新增案件」，填寫：

- **案件編號**（必填、不可重複，例如 `TP115-001`）
- **計畫名稱**（預設「115年度臺北市通學區規劃分析案」，可修改或建立其他年度）
- 學校名稱、行政區
- **負責人姓名、負責人 Email**：每日提醒信會寄到這個 Email。輸入既有同事姓名會自動帶入 Email；輸入新的 Email 時（限管理員），系統自動建立「僅收提醒」的帳號，該同事不需登入也會收到提醒；若要讓他登入，請到「使用者管理」幫他重設密碼
- 機關名稱、承辦人、承辦人 Email
- 機關通知日、審查會議日期時間與地點、會勘日期時間與地點、會勘簡報上傳網址

日期**可以之後再填**。儲存後系統依期限規則自動建立工作：

- 填了機關通知日 → 建立「事前規劃報告書創稿」「發文」
- 填了審查會議 → 建立寄簡報、會議、會議紀錄、修正圖說創稿與發文
- 填了會勘 → 建立上傳簡報、會勘、會勘紀錄、修正圖說創稿與發文

### 4.1.1 匯入排程（Excel，管理員）

「學校案件 →**匯入排程（Excel）**」可上傳排程甘特圖（可一次選多個檔案，例如 115 年與 116 年）：

- 每所學校一列，右側日期依序為：**派案 → 交初規 → 審查會議 → 會勘**；年份依上方「115/1」這類月份標題判斷。
- 派案日＝機關通知日；交初規＝提供事前規劃報告書期限（與系統計算不同時會自動鎖定為排程表日期）。
- 審查會議與會勘時間預設上午 10:00（註明「下午」者為 14:00），若案件已有同一天的時間則保留原時間。
- 相同計畫與學校名稱的案件會更新；沒有的會新增（案件編號如 115-01），負責人預設為匯入者。
- 承辦人簡稱（如「珠」）會自動對應全名（如「麗珠」）；交工、學校所在、延伸里與備註會寫入案件備註。
- 勾選「今天以前的工作自動標記為已完成」，可避免過去的工作產生逾期提醒。
- 先預覽確認再按「確認匯入」；同一份檔案重複匯入不會重複建立案件。

### 4.2 變更日期（改期）

1. 案件頁點「編輯案件／變更日期」。
2. 修改日期，並填寫「日期異動原因」。
3. 按「預覽期限變更」，系統列出每項工作的原期限 → 新期限：
   - **更新期限**：未完成的工作會改為新期限
   - **已完成，保留紀錄**：已完成的工作不會被改回未完成
   - **人工鎖定，不變更**：您手動指定期限的工作不受影響
4. 確認無誤後按「確認儲存並更新期限」。異動會記錄在「期限異動紀錄」。

### 4.3 案件頁其他功能

- **期程工作**：每項工作可「標記完成」或「調整」（狀態、人工鎖定期限、負責人、是否納入每日提醒）。人工鎖定期限必須填寫原因；清空日期即恢復系統計算。
- **審查會議／現場會勘**：顯示目前排定與改期歷史；會後點「標記已辦理」可填寫出席人員與紀要，並完成「審查會議」或「現場會勘」工作。
- **案件授權**：負責人或管理員可授權其他同仁「可編輯」或「僅檢視」。未授權的同仁看不到此案件。
- **公文、Email 草稿**：可直接建立對應草稿。
- **刪除案件（僅管理員）**：「學校案件」列表每列與案件頁都有「刪除」按鈕。確認視窗會列出將一併刪除的工作、公文、Email 草稿數量；若含公文或 Email 草稿，需輸入案件編號才能刪除。刪除後無法復原，紀錄保留在「操作紀錄」。只是不再執行的案件，建議改將狀態設為「已取消」以保留資料。

## 5. 工作待辦

- 上方切換「未完成／已逾期／已完成／全部」。
- 可依分類（創稿、發文、Email、上傳簡報、會議／會勘）、工作類型、狀態、負責人篩選；點表頭排序。
- 點工作名稱可查看詳情與期限異動歷史。

> **創稿與提供圖說是兩項獨立工作。** 標記創稿完成不代表已提供圖說（正式發文）。

## 6. 公文管理

### 6.1 建立與編輯

- **附件下載密碼（自動帶入）**：`CD80@` ＋ 提供報告或圖面日期（月日四碼）。事前規劃報告書依「提供事前規劃報告書」日期、修正圖說依「審查後／會勘後提供修正圖說」日期；例如萬大國小 10/19 → `CD80@1019`。
- **下載期限（自動帶入）**：創稿日期＋14 天；修改創稿日期時會跟著調整。舊公文可按「帶入預設密碼與下載期限」套用。
1. 從儀表板、工作待辦或案件頁點「產生公文」。
2. 系統依啟用中的範本帶入計畫名稱、學校名稱、機關通知日等資料。
3. 填寫：受文者、附件、**附件網址、下載密碼、下載期限**、正本、副本。
4. 右側「即時預覽」會即時顯示公文排版；尚未填寫的欄位會在下方提示。
5. 按「儲存草稿」。

下載密碼會加密儲存，不會以明文存在公文內文中；只有在預覽、複製與匯出時才會帶入。

### 6.2 複製與匯出

- **複製主旨／複製說明**：貼到機關電子公文系統。
- **匯出 DOCX／PDF、列印**：產生草稿排版文件（頁尾註明「非機關電子公文系統之正式發文」）。匯出前請先儲存。

### 6.3 標記狀態

1. **標記已創稿**：完成對應的「創稿」工作。
2. 於機關電子公文系統完成正式發文後，點 **標記已提供圖說**，輸入系統核發的**正式發文字號**與發文日期。系統不會自行產生發文字號。完成對應的「提供圖說」工作。
3. 已發文的公文不可再修改。不需要的草稿可「作廢」。
4. **刪除**：公文管理列表每一列、以及公文頁的操作區都有「刪除」按鈕，會先跳出確認視窗，刪除後無法復原。已發文的公文僅管理員可刪除；刪除紀錄會保留在「操作紀錄」。只想停用但保留紀錄時，請用「作廢」。

### 6.4 公文抬頭與 Email 簽名檔

- **發文單位資訊**（管理員）：「系統設定 → 發文單位資訊」填寫公司名稱、地址、聯絡人、電話、傳真、電子郵件，會顯示在公文抬頭。
- **Email 簽名檔**（每人各自設定）：「系統設定 → 個人帳號 → Email 簽名檔」，操作方式像 Word：
  - **先選取文字**，再用上方工具列調整**字型、大小、顏色、粗體／斜體／底線**；每個字都可以設定不同樣式。
  - **超連結**：選取文字（例如 Email 或電話）→ 按「🔗」→ 輸入網址、Email 或電話 →「套用連結」。Email 會自動變成「寄信」連結（mailto），電話變成撥號連結；按「🔗 斜線」可移除連結。
  - **圖片**：按「插入圖片」選擇 Logo 或名片圖檔；點一下圖片後可用 120／180／240… 按鈕或輸入數字調整寬度，也可以拖曳圖片右下角。
  - 按 Enter 換段、Shift+Enter 換行；改完按「**儲存簽名檔**」。Email 草稿中的 {signature} 會套用最新的簽名檔，內文中的 Email 與網址也會自動變成超連結。
- **寄出 Email（建議）**：在 Email 草稿頁按「**以郵件程式開啟**」，Outlook 會開啟新郵件並帶入收件人、副本、主旨與內文；簽名檔由 Outlook 自動加上（使用你在 Outlook 設定的簽名檔）。附加檔案後按「傳送」即可。
  - 請在 Outlook「檔案 → 選項 → 郵件 → 簽名」確認「新郵件」已選擇你的簽名檔。
  - 備用方式：「下載郵件檔（備用）」會下載一個郵件檔，點一下即以 Outlook 開啟含本系統簽名檔的新郵件。
- 也可以按「**複製內文（含簽名圖片）**」再到 Outlook 新郵件內文按 Ctrl+V；若貼上後字型、顏色跑掉，請在 Outlook「檔案 → 選項 → 郵件 → 編輯器選項 → 進階 → 剪下、複製和貼上」將「**從其他程式貼上**」設為「**保持來源格式設定**」。
- **第幾次通知**：在案件的「機關第幾次通知」填數字（例如 11），寄送簡報的 Email 會顯示「第11次通知」。

## 7. Email 草稿

1. 點「產生 Email」，系統帶入計畫名稱、學校、會議／會勘日期、承辦人、收件人、附件名稱與內文。
2. 可修改後「儲存草稿」。
3. 使用「複製收件人／主旨／內文」或「以郵件程式開啟」，**由您在自己的郵件程式附上正式附件後寄出**。
4. 寄出後回到系統點「我已寄出，標記完成」，勾選確認後送出，對應工作即完成。

5. **刪除**：Email 草稿列表每一列、以及草稿頁都有「刪除」按鈕，確認後永久刪除、無法復原。已確認寄出的 Email 僅管理員可刪除；刪除紀錄保留在「操作紀錄」。只想停用但保留紀錄時，請用「作廢」。

> 系統不會自動寄送這些業務信件，以避免誤寄附件。

會勘前的「上傳會勘簡報」不需寄信：點「開啟上傳網址」上傳後，標記完成即可。

## 8. 行事曆

- 切換「月／週／清單」，以箭頭切換期間，「今天」回到本日。
- 顏色：黃＝創稿、藍＝發文、綠＝Email、紫＝上傳簡報、紅＝會議／會勘；灰底為非工作天，並標示假日名稱。
- 可依學校、承辦人、工作類型篩選。
- 「匯出 ICS」可匯入 Outlook、Google 日曆（含今日前 30 天至未來一年的工作）。

## 9. 每日提醒

- 每個工作天上午 9:00～9:30 之間自動寄送提醒信，內容包含今日到期、未來 N 個工作天內到期、已逾期的工作與案件連結。
- 提醒對象：
  - **寄給負責同事**（工作負責人；未指派時為案件負責人）的只有 5 種：**提供事前規劃報告書、上傳會勘簡報、提供審查簡報、審查後提供修正圖說、會勘後提供修正圖說**。
  - **其他工作**（各項創稿、事前規劃報告書提供圖說、審查會議、會勘、Email 會議／會勘紀錄）不會寄給同事。
  - **管理員（專案經理）會收到所有工作的提醒**（包含上述 5 種）。
- 「提供事前規劃報告書」預設為機關通知日後第 12 個工作天，可於「系統設定 → 期限規則」調整。
- 同一天只會寄一次。
- **手動立即寄送**：網站（Render 免費方案）本身無法寄信，請到 GitHub 儲存庫 → **Actions →「每日提醒」→「Run workflow」** 執行，信件由 Gmail 寄出。網站上的「立即執行每日提醒」會顯示此說明。
- 「系統設定 → 通知設定」可調整：是否接收 Email、是否接收每日摘要、是否接收逾期通知、提前提醒工作天數。
- 「提醒紀錄」可查看自己的寄送紀錄。
- **預覽提醒信（管理員）**：「提醒紀錄 → 預覽提醒信」選擇一位同事，即可看到他今天會收到的提醒信內容；只是預覽，不會寄出。
- **補寄提醒信（管理員）**：在預覽頁按「**補寄這封信**」，立即把這封信再寄一次給該同事（不受「每日只寄一次」限制，會留下寄送紀錄）。
  - 尚未設定一鍵補寄時，畫面會列出步驟：到 GitHub「每日提醒」→「Run workflow」→ 在「補寄」欄位貼上同事 Email → 綠色「Run workflow」。
  - **設定一鍵補寄（只需做一次）**：
    1. GitHub 右上角頭像 → **Settings** → 左側最下方 **Developer settings** → **Personal access tokens → Fine-grained tokens** → **Generate new token**。
    2. Token name 填「補寄提醒信」；Expiration 選 1 年；Repository access 選 **Only select repositories** 並勾選本系統的儲存庫。
    3. Permissions → Repository permissions → **Actions** 改為 **Read and write**，按最下方 **Generate token**，複製產生的金鑰（只會顯示一次）。
    4. Render → 本網站服務 → **Environment** → Add Environment Variable，新增三筆：
       - `GITHUB_DISPATCH_TOKEN`：剛剛複製的金鑰
       - `GITHUB_REPOSITORY`：GitHub 帳號/儲存庫名稱（例如 `wandalin0057/116-school-schedule`）
       - `GITHUB_DISPATCH_REF`：`claude/school-zone-project-management-py4y8z`
    5. 按 Save Changes，等網站重新部署完成，之後按「補寄這封信」即自動寄出（約 1～2 分鐘送達）。

## 10. 管理員功能

### 10.1 使用者管理
新增使用者（設定角色與初始密碼）、編輯姓名與角色、停用帳號（立即登出、資料保留）、重設密碼。系統至少需保留一位啟用中的管理員。
- **一般使用者初始密碼**：「系統設定 → 使用者管理」上方輸入初始密碼後按「儲存初始密碼」（只以加密形式保存）。
  - 「將所有一般使用者密碼重設為初始密碼」：所有啟用中的一般使用者（不含管理員）改用初始密碼，需重新登入。
  - 新增一般使用者時密碼可留空，新增案件時自動建立的負責人帳號也會使用初始密碼。
  - 使用初始密碼登入的同事，每頁上方會提醒「請盡快變更密碼」；使用者清單會標示「初始密碼」。

### 10.2 通知設定（Email）
- **測試模式**：所有提醒改寄測試收件人，主旨加註［測試］。正式啟用前請先測試。
- **非工作天不寄送**。
- **寄送測試信**：確認寄信服務設定正確。
- 「提醒紀錄」頁可「立即執行每日提醒」（已寄出者不會重寄，失敗者會重試），並查看排程執行紀錄。

### 10.3 工作天設定
1. 至[政府資料開放平臺](https://data.gov.tw/dataset/14718)下載「中華民國政府行政機關辦公日曆表」該年度 CSV。
2. 「匯入官方辦公日曆」選擇檔案 → 「解析並預覽差異」，檢查解析結果與期限變動。
3. 填寫匯入原因 → 「確認匯入」。
4. 前往「期限重新計算」套用。

**手動調整**：颱風停班等臨時休假或補行上班，輸入日期、類型與原因後新增；刪除也需填原因。所有異動都會記錄。

### 10.4 期限重新計算
日曆或規則更新後，列出所有進行中案件的期限差異；填寫原因後套用。已完成與人工鎖定的工作不受影響。

### 10.5 期限規則管理
可修改各工作的名稱、工作天位移（負數＝事件前、正數＝事件後）與啟用狀態。儲存前可「預覽差異」，並可選擇立即重新計算。修改需填原因。

### 10.6 公文與 Email 範本
編輯主旨與內容，可使用 `{projectName}`、`{schoolName}`、`{notificationDateROC}`、`{attachmentUrl}`、`{attachmentPassword}`、`{downloadDeadlineROC}` 等變數（頁面右側有完整列表與範例預覽）。每次儲存產生新版本，可在版本紀錄切換回舊版。已建立的草稿不受影響。

### 10.7 資料備份與操作紀錄
- 「資料備份」下載 JSON 備份（不含密碼）。正式環境以資料庫自動備份為主。
- 「操作紀錄」可依對象、操作者、關鍵字查詢所有異動。

## 11. 常見問題

**Q：為什麼期限旁邊顯示「暫估」？**
該年度尚未匯入完整官方辦公日曆，系統只排除週末，不會猜測國定假日。請管理員於公告後匯入。

**Q：改了會議日期，已完成的工作為什麼沒變？**
已完成工作保留原紀錄，不會被改回未完成。若需重新辦理，可在工作「調整」中將狀態改回「進行中」，期限會依最新日期重新計算。

**Q：我看不到某個學校的案件？**
您不是該案件負責人，也尚未被授權。請洽案件負責人或管理員授權。

**Q：匯出的 PDF 可以直接當正式公文嗎？**
不行。匯出檔僅為草稿排版，正式發文請於機關電子公文系統辦理，再回填正式發文字號。
